# 模型 × 硬件矩阵

端侧 AI 最大的痛点是碎片化:同一个模型,在 RK3588、Jetson、ESP32、手机 NPU 上是完全不同的工具链与性能。这个矩阵用社区众包的实测数据回答——

> **哪个模型、量化到什么程度、在哪块板子上、什么功耗下,能跑到什么性能?**

::: tip 第一条数据等你来写
矩阵数据仓库 `Scintela/matrix` 建设中。贡献流程见[贡献指南](https://github.com/Scintela/.github/blob/main/CONTRIBUTING.md):在 `bench/` 下记录环境快照、运行命令与原始输出,把结果加进矩阵——数据被合并即永久署名。
:::

## 字段说明

- **量化**:int8 / int4 / fp16 / 原始精度
- **指标 / 数值**:一行一个指标——单帧延迟(ms)、吞吐(fps / tok/s)、首字延迟(ms)等,语音、视觉、LLM 各用各的自然单位
- **状态**:「待复现」→「已验证 ✓」(有人按你的环境快照独立复现成功后升级)
- **功耗**:整机功耗(W),注明是否含外设
