# 关于 Scintela

**Scintela · 星烁开源社区** —— 一个专注于**端侧 AI 与嵌入式智能系统**的开源技术社区。

*Small Sparks. Open Intelligence.*

我们汇聚工程师、开源爱好者和高校学生,共同探索轻量化、开放和可复现的端侧智能技术。

## 技术方向

- Embedded AI & TinyML
- Embedded Agent Runtime
- Linux / RTOS / BSP
- Model Deployment & Optimization
- AIoT & Intelligent Hardware

## 我们怎么做

- **可复现**:不接受无来源的跑分,每条数据附环境快照与复现命令
- **署名**:谁贡献,谁留名——矩阵、教程、点亮榜全部永久署名
- **开放**:内容 CC BY-SA 4.0,代码 Apache-2.0,中文为源、双语并行
