# About Scintela

**Scintela · 星烁 Open Source Community** — an open source community focused on **on-device AI and embedded intelligent systems**.

*Small Sparks. Open Intelligence.*

We bring together engineers, open source enthusiasts and students to explore lightweight, open and reproducible on-device intelligence.

## Technical Directions

- Embedded AI & TinyML
- Embedded Agent Runtime
- Linux / RTOS / BSP
- Model Deployment & Optimization
- AIoT & Intelligent Hardware

## How We Work

- **Reproducible**: no unsourced benchmarks — every row ships with an environment snapshot and reproduction commands
- **Credited**: whoever contributes gets permanent credit — matrix, tutorials, lightboard
- **Open**: content CC BY-SA 4.0, code Apache-2.0; Chinese as source, bilingual by design
